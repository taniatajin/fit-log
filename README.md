# 🏋️ FitLog — Workout Library & Planner

FitLog is a dark, no-nonsense gym companion. Browse a library of lifts, open
detailed instructions, lock workouts into today's plan, and save others for later.

🔗 **Live:** <https://fit-log-tau-six.vercel.app>

## Technologies Used

- Next.js (App Router)
- TypeScript
- React (Context API for state management)
- Tailwind CSS
- Lucide React (icons)
- React Hot Toast (notifications)

## Key Features

1. **Workout Library:** responsive grid of workouts fetched from an API, with a loading animation
2. **Sort and Search:** sort by duration, calories or rating, and search by name or muscle group
3. **Dynamic Details Page:** specs, instructions and tags for each workout
4. **Today's Plan and Saved List:** add workouts from the details page, with live navbar counters and a 5-lift cap
5. **My Plan Page:** live totals for exercises, minutes and calories, plus Mark as Done and Remove actions
6. **Toast Notifications and localStorage:** instant feedback, and data survives a page reload
7. **Fully Responsive:** works on mobile, tablet and desktop, with a custom 404 page
